# ফোন সহায়ক (PhoneHelper)

দুটো কাজের অ্যান্ড্রয়েড অ্যাপ:

1. **ফোন কোথায় রাখলাম ফাইন্ডার**: দুইবার জোরে হাততালি দিলে ফোন ফুল ভলিউমে বাজবে (সাইলেন্ট থাকলেও)।
2. **ফোন-পিকআপ কাউন্টার**: প্রতিদিন কতবার ফোন আনলক করলে তা গুনে রাখবে, গত ৭ দিনের হিসাবসহ।

## APK বানানোর সবচেয়ে সহজ উপায় (কম্পিউটারে কিছু ইনস্টল না করে)

1. github.com-এ বিনা পয়সায় অ্যাকাউন্ট খোলো।
2. নতুন একটা রিপোজিটরি বানাও (নাম: PhoneHelper)।
3. এই জিপের সব ফাইল (`.github` ফোল্ডারসহ) রিপোজিটরিতে আপলোড করো।
4. রিপোজিটরির **Actions** ট্যাবে যাও, **APK বানাও** চাপো, তারপর **Run workflow**।
5. ৩-৫ মিনিট পর কাজ শেষ হলে নিচে **PhoneHelper-debug-apk** নামে ফাইল পাবে। ডাউনলোড করে জিপ খুললে `app-debug.apk` পাবে।
6. APK ফোনে নিয়ে ইনস্টল করো (ফোনের সেটিংসে "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হতে পারে)।

## বিকল্প: Android Studio দিয়ে
Android Studio-তে এই ফোল্ডারটা Open করো, তারপর Run চাপো।

## ব্যবহার
- অ্যাপ খুলে সুইচ চালু করো, মাইক্রোফোন ও নোটিফিকেশনের অনুমতি দাও।
- ফাইন্ডার: হাততালি ধরছে না বা বেশি ধরছে মনে হলে "সংবেদনশীলতা" স্লাইডার বদলাও।
- ফোন রিস্টার্ট করলে পিকআপ কাউন্টার নিজেই চালু হয়। ফাইন্ডারের জন্য একবার অ্যাপ খুলতে হয়।
- ফোন গরম বা ব্যাটারি দ্রুত কমলে ফাইন্ডার বন্ধ রাখো, কারণ মাইক্রোফোন সারাক্ষণ চালু থাকে।
